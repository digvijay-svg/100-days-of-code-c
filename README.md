# 100 Days of Code in C

This repository contains a daily C programming practice log and exercise solutions for a 100-day learning challenge.

## Repository structure

- `Clanguage/` — daily C challenge files grouped by day
- Each day contains multiple practice questions and small standalone programs
- Files are designed to be simple, beginner-friendly C exercises

## Goals

- Practice core C concepts such as variables, loops, conditionals, arrays, functions, and pointers
- Build confidence by solving small daily problems
- Track progress across 100 days of consistent coding

## Example usage

To compile a single program with GCC:

```bash
gcc Clanguage/day15.c/q30.c -o q30
./q30
```

## Notes

This project is meant for learning and experimentation. Most programs are intentionally small and focused on a single concept.
